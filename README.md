# カーチェイス! 🚗🚓

パトカーから逃げきるブラウザゲーム。HTML/Canvas のみで動作します。

**▶ プレイする: https://ryonma-git.github.io/car-chase-game/**

## 遊び方

- **← → / A D** — 左右に移動
- **↑ ↓ / W S** — 加速・減速
- **スペースキー / タップ** — スタート・リトライ
- スマホはスワイプで操作できます

一般車にぶつかると大きく減速し、後ろのパトカーに追いつかれます。
捕まったらゲームオーバー。走った距離がスコアになります。

## ローカルで動かす

`index.html` をブラウザで開くだけです。
