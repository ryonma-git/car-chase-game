# カーチェイス! 🚗🚓

パトカーに追われながら、60秒以内にゴールを目指す三人称カーチェイスゲーム。
HTML/Canvas の1ファイルだけで動く擬似3Dレーサーです。

**▶ プレイする: https://ryonma-git.github.io/car-chase-game/**

## 遊び方

- **← → / A D** — ハンドル(左右)
- **↑ ↓ / W S** — 加速・減速
- **スペース / クリック / タップ** — スタート・リトライ
- スマホは画面の左右をタッチでハンドル操作

スタートすると **3・2・1・GO!**。制限時間は **60秒**。
**田舎 → 都会 → トンネル → 海峡大橋 → 田舎 → 都会 → 🏁ゴール** の一本道を駆け抜けます。

- カーブは曲がりきれ! 標識が先の曲がりを知らせます。
- 他車・ビル・壁にぶつかると減速し、後方のパトカーが接近(バックミラーと接近度メーターで確認)。
- **60秒以内にゴールで勝ち**。タイムアップ、またはパトカーに捕まると負け。
- 走行中に朝→昼→夕→夜へと時間が変化します。ベストタイム(残り秒)を記録。

## ローカルで動かす

`index.html` をブラウザで開くだけです。ローカルサーバーで動かす場合:

```bash
python3 -m http.server 8787
# → http://localhost:8787/
```
